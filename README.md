## امکانات کلیدی برنامه

- **مربی مکالمه صوتی رو‌در‌رو (AI Speaking Coach)**: گفتگوی زنده صوتی با آواتار طبیعی خانم (**Sarah Miller**) و آقا (**David Mitchell**)، تحلیل روانی گفتار، تصحیح گرامری و حالت کاملاً آفلاین و آنلاین (Gemini AI Logic).
- **فلش‌کارت و مرور هوشمند (FSRS)**: یادگیری واژگان عمومی و تخصصی مهندسی عمران با تلفظ آمریکایی و بریتانیایی، صدای مرد و زن، معنی فارسی و جمله‌سازی خودکار.
- **عمران و شبیه‌ساز جلسات (Civil Engineering & Role-Play)**: ۲۰ سناریوی واقعی کارگاهی، قراردادی FIDIC، تصفیه‌خانه آب و فاضلاب، بتن و ژئوتکنیک.
- **پشتیبان‌گیری و بازیابی کامل**: خروجی کامل تنظیمات ظاهری، پیشرفت روزهای مطالعه، واژگان، جلسات و فایل‌های صوتی با امکان ذخیره در حافظه گوشی یا اشتراک‌گذاری با سایر برنامه‌ها.
- **بهینه‌سازی برای گوشی‌های شیائومی (MIUI / HyperOS)**، پشتیبانی از زبان فارسی (RTL) و انگلیسی (LTR)، تم روشن و تاریک و تنظیم اندازه فونت.

## راهنمای ساخت دستی APK (برای توسعه‌دهندگان)

این پروژه با **Kotlin + Jetpack Compose + Material 3 + Room + Gradle 9.3.1** توسعه داده شده است:

```bash
# اجرای تست‌های واحد و روبولکتریک
gradle :app:testDebugUnitTest

# ساخت فایل نصبی اندروید (APK)
gradle :app:assembleDebug
```

خروجی APK در مسیر زیر ایجاد می‌شود:
`app/build/outputs/apk/debug/app-debug.apk`
